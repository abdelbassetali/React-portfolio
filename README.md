# 🚀 React Portfolio / Web GIS Showcase

Welcome to my personal portfolio website! This project is built using React to showcase my web development and spatial data visualization projects.

## ✨ Features
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Dark/Light Mode:** Seamless theme toggling saved via `localStorage`.
- **Interactive UI:** Built with clean component architecture and smooth animations.

## 🛠️ Technologies Used
- **React.js** (JavaScript Library)
- **HTML5 & CSS3** (Styling & Layout)
- **Leaflet.js** (for web mapping and GIS integration)
- **Visual Studio Code**
